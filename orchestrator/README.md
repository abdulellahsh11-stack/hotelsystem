# طاقم ضيوف — أوركستريتر لكل اشتراك

وكيلٌ رئيسي (Orchestrator) يتلقّى أوامر المالك ويوزّعها على **طاقمٍ من
الوكلاء المتخصّصين** (استقبال · خدمات غرف · صيانة · محاسبة). كل طاقمٍ
مسؤولٌ عن **اشتراكٍ واحد، ورقمُه رقمُ الاشتراك** (`client_id`)، ويتصل
بمنصّة ضيوف عبر مفتاح API الخاصّ بذلك الاشتراك.

> **مبدأٌ أساسي — «خبرٌ بكل حركة»:** كل أمرٍ، وتفويضٍ، ونداء أداةٍ، ونتيجةٍ
> يُسجَّل في `_activity/team_<الرقم>.jsonl` **ويُبثّ حيّاً** إلى الطرفية.
> لا حركة بلا أثرٍ يراه المالك.

## التشغيل المحلّي

```bash
pip install -r requirements.txt          # anthropic + httpx (موجودان في المستودع)

export ANTHROPIC_API_KEY=sk-ant-...       # أي نموذج — يُضبط بـ ORCH_MODEL
export DHEUOF_API_KEY=dhk_...             # مفتاح API الخاصّ بالاشتراك (من لوحة المالك)
export DHEUOF_BASE_URL=https://dheuof.com # أو http://localhost:5050 محلّياً

# أعطِ الطاقمَ أمراً — وشاهد كل حركة حيّة:
python -m orchestrator --subscription 11223344 "كم غرفة متاحة اليوم؟"

# أو راقب سجلّ حركة طاقمٍ سابق:
python -m orchestrator --subscription 11223344 --watch
```

## البنية

```
config.py        إعداد الطاقم من البيئة (رقم الاشتراك = رقم الطاقم)
activity.py      «خبرٌ بكل حركة» — سجلّ JSONL + بثٌّ حيّ لكل حدث
dheuof.py        عميل واجهة ضيوف المفتوحة، مصادَقاً بمفتاح الاشتراك
roles.py         الطاقم: أدوارٌ متخصّصة بأضيق نطاق (لا وكيل عام الغرض)
tools.py         أدوات النموذج ↔ نداءات ضيوف، كلٌّ مسجَّل
agent.py         حلقة الوكيل: نموذج → أداة → نتيجة → تكرار
orchestrator.py  الوكيل الرئيسي: يفوّض لكل دورٍ عبر أداة delegate
team.py          Team = اشتراقٌ واحد جاهزٌ لاستقبال الأوامر
__main__.py      تشغيلٌ محلّي (CLI) + مراقبة الحركة
```

## النموذج والصلاحيات

- **أي نموذج**: يُضبط بـ `ORCH_MODEL` (الافتراضي `claude-opus-5`).
- **العزل**: مفتاح الاشتراك مرتبطٌ برقم المنشأة على الخادم، فلا يبلغ الطاقمُ
  بيانات اشتراكٍ آخر. وكل دورٍ محدود الأدوات (الاستقبال لا يرى المالية، إلخ).
- **المساءلة**: `team.activity_log()` وملفّ الـJSONL يحفظان كل حركةٍ بفاعلها.

## خارطة الطريق — النقل إلى السحابة

يعمل الطاقم الآن **على جهازك**. عند التوسّع يُنقل كل طاقمٍ إلى **وكيل
سحابةٍ صغيرٍ مستقل**، ورقمُه يبقى رقم الاشتراك (لا يتغيّر عند النقل).
المتبقّي للتشغيل المستمرّ ٢٤/٧ (خارج نطاق هذا الجزء):

1. **خادم/حاوية دائمة** لكل طاقم (systemd أو حاوية على Railway/Fly.io).
2. **مشغّل زمني (Heartbeat/Cron)** ليستيقظ الطاقم دورياً ويفحص المهام.
3. **قناة تنبيه** (واتساب/تيليجرام/بريد) لبثّ الحركة للمالك عن بُعد —
   حالياً البثّ للطرفية وملفّ الـJSONL.
